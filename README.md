# Election Data Analysis Using Python

##  Project Overview

This project analyzes election data using **Python and CSV file handling**. The program reads election data from a CSV file, processes the voting records, calculates the total number of votes, determines the percentage of votes received by each candidate, and identifies the winner.

This project was created to practice **Python programming, file handling, data processing, and basic data analysis**.

##  Technologies Used

* Python
* CSV File Handling
* Python Standard Library

##  Project Features

* Read election data from a CSV file
* Process voting records
* Count total votes
* Calculate candidate vote percentages
* Determine the winning candidate
* Generate an election results report

##  How It Works

1. The program opens the election CSV file.
2. The CSV data is read using Python's `csv` module.
3. The program processes each voting record.
4. Votes are counted for each candidate.
5. Vote percentages are calculated.
6. The candidate with the highest number of votes is identified as the winner.
7. The final results are generated in a report.

##  Output

The program generates an election results report containing:

* Total Votes
* Candidate Names
* Number of Votes
* Percentage of Votes
* Winning Candidate
